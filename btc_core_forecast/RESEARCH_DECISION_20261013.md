# Исходное ТЗ сохранено

Цель — работающая прогнозная система с подтверждённой пользой для возврата BTC-ядра. Изменение исходного документа, снижение требований, выдача исследовательских расчётов за подтверждённые прогнозы запрещены.

Исходный документ содержит минимум 4–8 недель проверки прогнозов, выпущенных до событий. Новая история, ранее использованная в проекте, не заменяет эту проверку. Постоянная разработка или дополнительный расход вычислений не создают будущие исходы раньше времени.

Дополнительная проверка причин предыдущей неустойчивости проведена двумя целевыми модулями:

- Условная совместная траектория: меняет будущую волатильность по причинным признакам и калибровочным траекториям. Средний CRPS лучше волатильностной базы во всех четырёх кварталах на 1/4/24 часа; часть описательных интервалов включает ноль. Устойчивое улучшение выбора входа не обнаружено. Неполное покрытие интервалов также препятствует допуску.
- Вероятность выгоды ожидания: классификатор, калибровка исключительно по завершённому периоду и один фиксированный порог. Выгода ожидания после часового исполнения не превосходит обе базы устойчиво; кандидат отклонён для торговли.

Торговый допуск обоих модулей остаётся выключенным. Исходные рабочие ветки, замороженный сборщик и зарегистрированные периоды не изменены. Новые модули не являются выпущенной подтверждённой моделью.

Непреодолимые сейчас условия полного подтверждения: нет завершённой перспективной проверки нового прогнозного кандидата; нет кандидата с устойчивой пользой для выбора входа; нет фактического журнала котировок, отказов и частичных исполнений оператора. Пропуски R6 и отсутствие исторических макровинтажей с доступным до публикации консенсусом сохраняются.

Следующий содержательный источник улучшения — проверяемые дополнительные признаки и новые прогнозы до событий; повторение уже отвергнутых схем не обосновано результатами. Промежуточные файлы не передаются пользователю как выполненная задача.

Воспроизведение: Python 3.12 с requirements.txt; OMP_NUM_THREADS=1; run conditional_path.py и entry_probability.py с --arrays long_results/regime_arrays_complete.npz, разными --output. Результаты диагностические, история уже известна. Никаких автоматических торговых действий.
