# Подписанный сбор данных для прогнозной системы BTC

Отдельный ограниченный сбор рыночных снимков. Это не торговая модель и не подтверждение прогностического преимущества. Исторические исследовательские кандидаты к торговле не допущены и здесь не запускаются.

Фиксированная сетка: 13 октября 2026 14:00 МСК — 14 октября 2026 14:00 МСК, 96 периодов по 15 минут. Подписанная регистрация должна появиться до начала. Предварительная проверка источников вынесена за сетку и не засчитывается в наблюдения.

Обязательные источники — закрытые свечи Binance BTCUSDT 1m/5m и текущий минутный поток. OKX OI, funding и стакан являются отдельными необязательными источниками: ошибки остаются явными, значения не заменяются. OKX не подставляется в признаки, обученные на Binance.

Все записи подписываются Sigstore и проверяются с точным исходным коммитом, личностью GitHub workflow, издателем сертификата и Rekor. Доверенный корень один раз получает и проверяет TUF; параллельные проверки далее используют его неизменяемую копию. Пропущенные периоды не восстанавливают задним числом исторический стакан или позиционирование.

Сбор идёт блоками до 90 минут на стандартном Ubuntu runner. Успешный блок запрашивает следующий запуск того же неизменного исходного коммита. После фиксированного конца новый запуск не запрашивается. Критический отказ фиксирует неуспешную задачу; автоматического обхода проверки нет.

Ветка исходников `btc-core-forward-source-20261013`, ветка данных `btc-core-forward-raw-20261013`. Основная ветка и действующие подписанные R5/R6 не меняются. Время публикации GitHub отдельно не считается независимым доказательством времени выпуска прогноза; прогнозы в этом сборе не выпускаются.
