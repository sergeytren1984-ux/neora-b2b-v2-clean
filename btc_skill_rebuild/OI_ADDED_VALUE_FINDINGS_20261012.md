# BTC v7R6 — численная ценность OI и funding, 12.10.2026

**Результат: отклонить OI как подтверждённое улучшение направления.** Только исследовательская математика. В действующие модели, GitHub Actions, расписания, подписи, сборщики, frozen SHA изменений не вносилось.

## Состав данных и осторожность по as-of

- Спотовые закрытые BTCUSDT 5m: 18 720 свечей 07.08–11.10.2026 UTC, источник Binance, SHA256 gzip `b590c60a8224bb15ac78fd28361954cd7e21825cb29a1aaa6758c801efe4fe7b`.
- Исторические Binance USDT-M open interest (8004 записей, 5m), COIN-M open interest (7998; некоторые пропуски) и funding (87 расчётных ставок), собраны на пользовательском Mac 11 октября. Исторические метки биржи **не доказывают фактическое время публикации/HTTP получения**. Эти данные не могут заменить подписанные as-of receipts и не могут обосновать prospective допуск.
- Консервативное математическое смещение: для решения в `t` использовать OI не позднее `t−5min`, а изменения OI от соответствующих строго предшествующих 15m/60m. Funding только предыдущая зафиксированная расчётная ставка. COIN-M — опциональный, со сроком давности и явным признаком отсутствия. Нет нулевой подстановки вместо **обязательного** USDT-M OI.
- Контроль от использования будущего: тесты доказывают, что добавление OI/funding с временной меткой `t` не меняет вход модели для прогноза в `t`, а отсутствие своевременного USDT-M не скрывается.

## Честная парная проверка без подмены базы

Модели сравниваются при тех же 15-минутных тестовых решениях, 4 взаимоисключающих исходах `UP_FIRST/DOWN_FIRST/NEITHER/AMBIGUOUS_SAME_5M`, тех же 1h ±0,7% и 4h ±1,2%, тех же строго предшествующих обучающих/калибровочных периодах. Обучение 5m используется для достаточности исходов OI на доступных двух неделях, в обеих ветках **одинаковое**. Проверка и тест — 15m. Код реализации *тот же* математический многоклассовый forecaster, который проверен для спота; меняется только набор входов. 13 пропусков обязательного OI исключены **из обоих** вариантов, а не только из augmented.

| Критерий | 1h | 4h |
|---|---:|---:|
| TRAIN / calibration / исторический test (совпадающие окна) | 4007 / 668 / 648 | 3971 / 656 / 636 |
| Brier только спот | 0,0410275 | 0,0608836 |
| Brier спот + OI/funding | 0,0409327 | 0,0610983 |
| **Прибавка Brier**, спот минус OI | **+0,0000948** | **−0,0002147** |
| **Прибавка в направлении** | **−0,0003123** | **−0,0005766** |
| Дней с улучшением Brier | 2 из 7 | 2 из 7 |
| Описательная нижняя 95% граница среднедневной Brier прибавки | **−0,0001203** | **−0,0007542** |
| Сигналы OI-версии в известной test | 2 | 0 |
| Правильные направленные сигналы OI-версии в test | **0** | **0** |

Ненулевая прибавка общей Brier на 1h мала, по независимым дням неустойчива, а направленная составляющая **ухудшилась**. На 4h ухудшилась даже общая Brier. При такой редкости направленных публичных предупреждений выборка не доказывает точность независимо от числа коррелированных 15m окон.

## Отдельный математический результат

Проверка с сохранением одинакового прогноза риска движения, но с *фиксированной TRAIN-долей UP/DOWN*, показала отрицательную добавленную ценность OI именно в предсказании знака. Увеличение OI само по себе не означает приток новых покупателей: оно может соответствовать входу и длинных, и коротких позиций. Механическое толкование растущего OI как `UP` запрещено.

## Решение по работе

1. Не увеличивать вероятность **UP** или **DOWN** только из-за роста OI; не продвигать данный исторический augmented вариант в действующую модель.
2. Считать исторический вероятностный выигрыш 1h преимущественно **оценкой риска**, а не возможностью своевременного направленного OTC решения.
3. Следующая математическая проверка возможна на **реально будущих подписанных** закрытых 3m taker-flow + contemporaneous independent book imbalance + OI с проверенным временем получения каждого источника, а не только vendor timestamps из прошлого.
4. Для допуска необходимы ≥20 независимых prospective дней **и достаточное число независимых направленных событий**, воспроизводимое преимущество против базовых решений по MAE/Brier/lead-time, а также подтверждённая экономическая выгода OTC после реальных отказов, спреда и задержек. Никакой обязательной даты успеха нет.

**Итог:** добавление исторического OI/funding к изученной математике не решило проблем прогноза направления. `trading_authority=false`, `predictive_skill_proven=false`.
